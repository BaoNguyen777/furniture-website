# Furniture Website Template (Next.js)

Template website cho cửa hàng nội thất xây bằng **Next.js App Router**, sẵn sàng mở rộng tính năng AI.

## Khởi chạy dự án

```bash
npm install
npm run dev
```

Mở trình duyệt tại `http://localhost:3000`.

## Mở rộng AI gợi ý

- Chatbot tư vấn sản phẩm theo nhu cầu khách hàng.
- Gợi ý nội thất theo ảnh phòng bằng computer vision.
- Sinh nội dung SEO cho mô tả sản phẩm.
- Cá nhân hóa khuyến mãi theo hành vi người dùng.

## Cấu trúc chính

- `app/`: App Router pages + global style.
- `components/`: Các section UI tái sử dụng.
- `data/`: Dữ liệu mẫu để dựng giao diện.
